# Lyrics

Standalone Android app for searching and playing Apple Music songs, importing TTML/LRC files, exporting lyrics, and customizing lyric display.

This project contains its own lyrics UI, Apple Music login/client, lyric parser, bundled `am-lyrics` WebView assets, player, cache manager, and status-bar lyric notification implementation. Runtime code is copied into this project and does not reference the parent Apple Music app's source tree.

Playback and Android media controls share one Media3 player/session so their playback state stays in sync.

Song search and playback remain in Apple Music. Search results request simplified-Chinese metadata and are supplemented from the China storefront when the same recording can be verified by ISRC; the original storefront song ID is retained for playback. When a track is loaded, a floating mini-player appears above the Home/Settings navigation bar with circular album art, title, artist, play/pause, next, and a progress ring around its rounded outer edge; tapping the capsule opens that track's lyrics page. The mini-player uses a mostly opaque surface that lets only a subtle hint of the background show through. The playback controls are also a floating overlay above the full lyrics viewport, with the progress ring around the control card rather than reserving additional lyric-page height. The card background is uniformly translucent and has no drop shadow; playback buttons, status, time, and lyric-timing metadata automatically use a high-contrast accent in dark mode. The live lyrics notification shows the current lyric as its title and the corresponding translation as a second line when available. Swipe up on the playback card to enter full-screen lyrics and swipe down to exit; the full-screen button is omitted. On the lyrics page, the floating Home/Settings bar hides after a period of inactivity and reappears when the lyrics are scrolled. Playback controls and secondary status text use an accent extracted from the current album artwork, independently of the Monet app theme; the song title and artist retain their normal text colors. In dark mode, lyric highlight colors are automatically brightened as needed for contrast and inactive lyrics fade less. The Settings theme card supports following the system appearance, forcing light mode, or forcing dark mode; select the Monet color circle to use the device wallpaper's dynamic primary color, or choose a manual palette. The playback cache manager combines the audio-cache limit control and a per-song view of audio and lyric cache entries. Playback audio cache has a user-adjustable 0.5–20 GB limit and evicts least-recently-used, unpinned songs when it exceeds the limit. Lyrics successfully fetched from Apple Music or QQ Music are persisted in the app's private files, associated with the Apple Music song ID, and reused on later visits to the same song; the lyric cache is source-specific and retains up to 500 entries. Apple Music word-timed lyrics are preferred; otherwise the app tries matching QQ Music QRC lyrics, then the existing online lyric sources. QQ searches use the localized title and artist alongside the original metadata. QQ lyrics use HyperLyrics-Enhanced's `GetPlayLyricInfo` flow: QRC, translation, and romanization are requested together; encrypted lyric text is read from the response's `lyric` field and decrypted as QRC, preserving word timing. The original QRC is parsed first and remains usable when the optional translation is empty or invalid. Separate translation lines are matched one-to-one to original lines by start time within 1 second. No legacy `lyric_download.fcg` request or inferred pairing of interleaved languages is used. When QQ returns a separate translation, it is shown by default and can be toggled; otherwise the original lyric remains visible and translation display stays off. The lyric download menu can also export the decrypted QQ QRC and translation payloads in a `*.qq-qrc.txt` diagnostic file for inspecting source timing/format. QQ candidates are ranked using title, artist, album, and duration; a cross-language top-result fallback still requires a duration difference within 2.5 seconds. Long-press the lyrics to open copy, download, source-selection, import, and display options; use the system Back action to return to search results.

The QQ QRC DES helper is adapted from [Lyricify-Lyrics-Helper](https://github.com/WXRIW/Lyricify-Lyrics-Helper) and is licensed under Apache-2.0; its license is included at `lyrics-tool/src/main/java/com/applemusic/lyricstool/data/qq/LICENSE-APACHE-2.0.txt`.

## Build

Open this directory in Android Studio, or run:

```powershell
.\gradlew.bat :lyrics-tool:assembleDebug
```

The debug APK is written to `lyrics-tool/build/outputs/apk/debug/lyrics-tool-debug.apk`.

The Android SDK must be configured in Android Studio or through `ANDROID_HOME`/`ANDROID_SDK_ROOT`.
